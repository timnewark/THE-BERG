TBS location lookup

Drop in the workbank: OS Ref → nearest postcode, what3words and nearest A&E, filled into the blank cells.

1. Workbank (Excel)

The downloaded workbook has the same sheets and data; cell formatting, formulas and macros are not kept, so if your workbank has those, copy the three columns from the table back into your own file instead.

Or type grid references

One per line, any precision, or easting, northing. A name before a colon labels it.

what3words API key

Free from developer.what3words.com. Kept only in this browser. Without a key, postcode and A&E still fill; What3Words is left blank.

Grid refs are converted at the centre of their square (a 6-figure ref is a 100 m square). Postcode is the nearest within 2 km (postcodes.io). A&E is the nearest consultant-led 24-hour emergency department from a built-in UK list (Nov 2026), straight-line distance. Check before relying on any of it for a RAMS.
