BridgeBuilder

Bridge inspection photos: take, name, and renumber into the report order.

Download BridgeBuilder (Android)
Version 1.0, build 59 · Android 8 or later · about 22 MB

Installing

  1. Tap the download button on the phone. When it finishes, open the file from the notification or from Files → Downloads.
  2. Android will ask to allow installs from this browser the first time: allow it, then tap Install.
  3. If Play Protect warns that the app isn't verified, tap Install anyway. It's a privately distributed app, not on the Play Store.
  4. Open BridgeBuilder, allow the camera, and choose the folder the bridge's photos go in.

Updating: download the newer build from this page and install over the top. Photos and settings are kept.

What it does

Take a photo, say or type its name (codes such as NEWW, SABT, AF are written out), and it saves straight into the bridge's folder. The Photo list checks the standard shots are all there, shows what's missing, and renumbers the photos into the report order in pairs. Settings has the structure type (one span bridge or retaining wall).

Tools: TBS location lookup (OS grid ref → postcode, what3words, nearest A&E).
